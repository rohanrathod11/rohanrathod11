## What I'm building

**Polaris** ([tradepolaris.com](https://tradepolaris.com)) brings market data, strategy testing, sourced research, and portfolio risk into one product. Two core products anchor it. **Aegis** is the institutional risk engine: risk cockpit, stress testing, efficient frontier, regime and attribution analysis on the book you actually hold. **Vega** is the research analyst: ask a question in plain English and get back the answer with the chart, the underlying query, and cited sources attached.

Around them sits the rest of the platform: a declarative Strategy Builder, walk-forward backtesting that reports out-of-sample folds with realistic costs, deflated Sharpe, and overfitting checks, plus point-in-time market data across 30,000+ tickers and six asset classes. That data is also exposed directly through the Kappa Data API, where every response is pinned to an immutable dataset version so a query run today reproduces exactly a year from now, and through a TradePolaris MCP server that brings the same market and portfolio context into any AI workspace.
